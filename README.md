# NOVA Rules

Неофициальный справочник правил NOVA RP (GTA 5 RP) для Windows.

- Поиск по всем пунктам правил: опечатки, словоформы, сленг (ДМ, РК, ПГ, капт).
- Правила по категориям: общие, мероприятия, криминальные, госструктуры, семьи, форум.
- Ежедневное автообновление и лента «Что изменилось в правилах».
- Быстрый поиск поверх игры по `Ctrl+Shift+Space`.
- Работает офлайн.

> Статус: в разработке.

## Приватность

Без телеметрии и аналитики. Приложение обращается только к CDN с данными правил, GitHub Releases (обновления) и форуму проекта (картинки из правил).

## Дисклеймер

Неофициальный справочник. Не связан с администрацией NOVA RP. Актуальная редакция правил — на форуме проекта: https://forum.grand-rp.su/

## Разработка

```
pnpm install
pnpm dev        # приложение
pnpm scrape     # сборщик правил
pnpm test
```
