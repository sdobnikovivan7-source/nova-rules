## Даты

- `pubDate` в RSS и дата в атрибуции поста — **дата создания темы**, правки по ним не видны.
- Дата последней правки: `article.message:first .message-lastEdit time[datetime]` (ISO с часовым поясом; текст бывает относительным — «Вчера в 11:45», брать только атрибут). Есть не у всех тем.
- **Вывод:** сборщик каждый день скачивает все ~40 тем (пауза 1,5–2 с → ~1,5 мин) и сравнивает хеши. Дата правки — для отображения «Обновлено …», не для решения «качать или нет».

## Посты в теме

- Правила целиком лежат **в первом посте**.
