# NOVA Rules для Twitch

Картинки пересобираются командой `pnpm twitch` из `panel.html` и `overlay.html`.

## Панель «О канале» — `panel.png`

Twitch → канал → «О себе» → «Редактировать панели» → «+» → загрузить `panel.png` (640×320, Twitch покажет её шириной 320 — будет чёткой).
В поле «Ссылка изображения» — `https://github.com/sdobnikovivan7-source/nova-rules/releases/latest/download/NOVA-Rules-Setup.exe`, тогда клик по панели сразу скачает установщик.

## Плашка на экране

**С анимацией (рекомендуется)** — OBS → «Источники» → «+» → «Браузер»:
- «Локальный файл» → `overlay.html` из этой папки;
- ширина 1920, высота 1080.

Плашка выезжает снизу слева, по очереди показывает три возможности и время от времени по ней пробегает блик. Фон прозрачный.

Параметры — снимите «Локальный файл» и вставьте адрес вида
`file:///C:/Users/sdobn/Desktop/NOVA/Nova/docs/promo/twitch/overlay.html?pos=br&show=20&every=300`:
- `pos=bl` (по умолчанию) / `br` / `tl` / `tr` — угол экрана;
- `show=20&every=300` — показывать 20 секунд раз в 5 минут (без них — всё время на экране).

Шрифты подтягиваются из `node_modules` проекта — файл нужно открывать из этой папки, не копировать отдельно.

**Без анимации** — источник «Изображение»:
- `overlay.png` — весь кадр 1920×1080 с плашкой в углу, просто положить поверх сцены;
- `overlay-banner.png` — только плашка, поставить куда угодно.

`overlay-preview.png` — как плашка смотрится поверх кадра игры.
