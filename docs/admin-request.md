Здравствуйте!

Я игрок NOVA RP, ник **<ник в игре / на форуме>**. Делаю бесплатное неофициальное приложение для Windows — **справочник правил проекта**, и хочу согласовать его с вами до того, как раздавать игрокам.

**Что умеет приложение**

- Поиск по всем пунктам правил из раздела «Правила проекта»: по номеру пункта, по словам с опечатками и по сленгу (ДМ, РК, ПГ, капт).
- Правила по категориям (общие, мероприятия, крайм, гос, семьи, форум), у каждого пункта есть кнопка «Открыть на форуме».
- Лента «Что изменилось в правилах», чтобы игроки не пропускали правки.
- Быстрый поиск поверх игры по горячей клавише.

**Как оно получает правила**

- С форума правила раз в сутки забирает **один** сборщик, а не каждый игрок. Это около 50 запросов в день с паузой 1,5–2 секунды между ними и честным User-Agent:
  `NovaRulesBot/1.0 (+https://github.com/sdobnikovivan7-source/nova-rules)`
- Сборщик запускается автоматически на GitHub Actions раз в сутки, в 06:07 по Москве.
- Игроки получают уже готовые данные с GitHub, сам форум их приложения не нагружают. Нагрузка на форум не растёт от числа пользователей.

**С чем нужна помощь**
Недавно на форуме включили проверку браузера (страница «Проверка браузера», ответ 401 без JavaScript). Сборщик её не проходит, поэтому правила в приложении перестали обновляться. Обходить защиту я не хочу и не стал. Можно ли один из вариантов:

1. пропускать мимо проверки запросы с User-Agent `NovaRulesBot` к разделу «Правила проекта» (`/forums/893/` и вложенные разделы, темы правил и их RSS);
2. или пропускать запросы с серверов GitHub Actions (список IP-адресов публикует GitHub: https://api.github.com/meta, раздел `actions`);
3. или, если удобнее, — любой другой способ, который вы предложите (например, отдельная ссылка или выгрузка правил).

**Что гарантирую**

- Без рекламы, без телеметрии и сбора данных игроков. Исходный код открыт: https://github.com/sdobnikovivan7-source/nova-rules
- В приложении указано, что это неофициальный справочник, а актуальная редакция правил — на форуме. Логотип и фирменные элементы NOVA RP без вашего разрешения не используются.
- Если вы попросите что-то изменить или убрать, сделаю.

4. Если приложение окажется полезным — возможно ли закрепить ссылку на форуме или в Discord?
