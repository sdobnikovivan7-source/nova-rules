Я игрок NOVA RP, ник **<ник в игре / на форуме>**. Делаю бесплатное неофициальное приложение для Windows — **справочник правил проекта**, и хочу согласовать его с вами до того, как раздавать игрокам.

**Что умеет приложение**
- Поиск по всем пунктам правил из раздела «Правила проекта»: по номеру пункта, по словам с опечатками и по сленгу (ДМ, РК, ПГ, капт).
- Правила по категориям (общие, мероприятия, крайм, гос, семьи, форум), у каждого пункта есть кнопка «Открыть на форуме».
- Лента «Что изменилось в правилах», чтобы игроки не пропускали правки.
- Быстрый поиск поверх игры по горячей клавише.

**Как оно получает правила**
- С форума правила раз в сутки забирает **один** сборщик, а не каждый игрок. Это около 40–50 запросов в день с паузами между ними, с честным User-Agent `NovaRulesBot`. Нагрузка на форум не растёт от числа пользователей.
- Игроки получают уже готовые данные с GitHub, сам форум их приложения не нагружают.
